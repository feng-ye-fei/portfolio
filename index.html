关于我

我的项目

个人作品集网站

使用纯 HTML 语义化标签搭建的个人介绍页面，包含头像、个人简介、项目展示和 GitHub 链接，不使用 CSS 和 JavaScript，用来练习页面结构与内容组织，也是 vibe coding 学习的第一个实践成果。

技术栈：HTML5、语义化标签、锚点导航

基于 ESP32 的温湿度环境监测系统

用 DHT11 传感器采集环境温湿度，ESP32 通过 Wi-Fi 把数据上传到局域网页面，并在 OLED 屏上实时显示，超过设定阈值时点亮提示灯。

技术栈：ESP32、DHT11、OLED、Wi-Fi、C

智能家居控制原型

以 MQTT 协议连接 ESP32 与手机端，实现 LED 灯和继电器的远程开关，并回传设备当前状态，作为物联网系统课程设计的综合实践。

技术栈：ESP32、MQTT、Python、传感器与执行器
